# Learning Log - Python 基础练习

这是我的 Python 学习记录仓库，用于保存日常的练习代码和简单的小项目。

## 📂 项目结构

- `first/`：Python 基础语法练习
  - `calculator.py`：简易计算器
  - `converter.py`：单位转换器
  - `hello.py`：Hello World 及基础输入输出
- `second/`：if语句基础
  - `evenodd.py`：判断奇偶数
  - `grade.py`：成绩等级判断
- `third/`：循环语句基础
  - `dict.py`：字典操作
  - `loop.py` / `loop1.py` / `loop2.py`：循环结构练习
  - `九九乘法表.py`：打印九九乘法表
  - `求1到100的和.py`：循环求和
  - `猜数字游戏.py`：一个简单的猜数字控制台游戏

## 🛠️ 环境要求

- Python 3.x

## 🚀 如何运行

1. 确保本地已安装 Python 3。
2. 打开终端，进入对应文件夹，例如运行猜数字游戏：
   ```bash
   cd third
   python 猜数字游戏.py
   ```
